# The Library is folders of .canvas files in app data

The app keeps one Library in a `Library` folder inside the OS app-data location (`QStandardPaths::AppDataLocation`). Each Project is a subfolder, and each Canvas is an ordinary JSON Canvas file inside it. Like tldraw, the app owns where Canvases live. There is no opening or saving of arbitrary files, and no Canvas exists outside a Project. We considered two alternatives: one bundle file per Project (as a `.tldr` file holds every page), and a single database. We chose plain folders and files because they reuse the existing JSON Canvas load/save unchanged and need no new format. Everything the files can't hold (the order of Projects and Canvases, each Canvas's view, what was open last) goes into one index file at the Library root. The phase-2 sync unit stays a single Canvas, so Projects never touch the sync layer.
